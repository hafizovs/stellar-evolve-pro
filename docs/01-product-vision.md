## 1.1 Продукт

| Поле | Значение |
|------|----------|
| Название | **StellarEvolve Pro** |
| Подзаголовок (RU) | Симулятор эволюции звёзд и HR-диаграммы |
| Подзаголовок (EN) | Stellar Evolution & HR-Diagram Simulator |
| Тип | SPA, образовательно-научная интерактивная астрофизическая лаборатория |
| Платформа | Современный desktop Chrome/Firefox/Edge; mobile — usable (панели collapsible), desktop — primary |
| Рендер | HTML5 Canvas 2D (звезда) + чистый SVG (HR-диаграмма) |
| Научный уровень | Параметрическая эволюция звезды по scaling relations + Stefan–Boltzmann + упрощённые треки стадий; не полный MESA/1D hydro |

**Ценность:** дать пользователю «пульт обсерватории», где можно задать массу и металличность, прожить жизнь звезды от протозвезды до остатка и увидеть, как точка движется по диаграмме Герцшпрунга–Рассела в реальном времени.

**Аудитория:** студенты астрофизики/астрономии, преподаватели, энтузиасты космоса, разработчики, изучающие Angular + scientific visualization.

## 1.2 Информационная архитектура экрана

Один главный экран (без роутинга страниц) — **Control Room**:

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Toolbar: StellarEvolve Pro | presets | theme | lang | screenshot | hotkeys   │
├─────────────────────────────┬────────────────────────────┬───────────────────┤
│                             │                            │ Telemetry         │
│   Stellar View (Canvas)     │   HR-Diagram (SVG)         │  - age / remaining│
│   + Core Cross-Section      │   grid + MS + regions      │  - stage / process│
│   toggle                    │   live track + marker      │  - composition    │
│                             │                            │  - Teff, L, R, M  │
├─────────────────────────────┴────────────────────────────┴───────────────────┤
│ Bottom: Mass | Metallicity | Play Pause Reset | Time accel | adaptive dt HUD │
└──────────────────────────────────────────────────────────────────────────────┘
```

- Левая колонка (~38%): Canvas звезды + тумблер «Разрез ядра».
- Центральная колонка (~42%): SVG HR-диаграмма.
- Правая колонка (~320–360px): телеметрия и состав ядра.
- Нижняя панель (72–88px): входы M/Z, плеер времени, readout `dt`.
- На ширине `< 1100px`: HR и телеметрия — вкладки / drawer; Canvas остаётся сверху.
- Z-index: visuals (0) < panels (10) < bottom bar (15) < drawers/modals (30).

## 1.4 User Journeys (обязательные сценарии)

### J1 — Первый запуск / Солнечный сценарий
1. Пользователь открывает приложение.
2. Тема: **dark**. Locale: **ru**.
3. Начальные параметры: \(M = 1\,M_\odot\), \(Z = 0.02\) (солнечная металличность) из [appendix-a-defaults.md](appendix-a-defaults.md).
4. Симуляция: **paused**; звезда на стадии `protostar` или сразу на ZAMS после «Запустить» — по умолчанию после load показывается ZAMS preview без записи трека до Play.
5. HR показывает сетку, статическую главную последовательность и пустой / стартовый маркер.
6. Телеметрия показывает текущие \(T_{\mathrm{eff}}\), \(L\), \(R\), стадию, состав.

### J2 — Запуск эволюции
1. Пользователь нажимает **Запустить эволюцию** (или Space).
2. Clock тикает с адаптивным `dt`; параметры звезды обновляются через Signals.
3. На HR появляется эволюционный трек; маркер следует за текущей точкой.
4. Текстовое описание процессов обновляется по стадии (например: «В ядре идёт горение водорода (pp-цикл)»).

### J3 — Смена начальной массы / металличности
1. Пользователь двигает слайдер массы или Z.
2. Если симуляция уже шла — требуется **Reset** перед применением новых начальных условий **или** слайдеры disabled во время play (выбери и зафиксируй: **слайдеры disabled while playing / after first step until Reset**).
3. Reset очищает трек, возвращает к начальным M/Z, стадия = protostar/ZAMS preview, age = 0.

### J4 — Разрез ядра
1. Тумблер «Разрез ядра» / «Core Cross-Section».
2. Canvas переключается на слоистую схему: ядро (с доминирующим элементом), радиационная зона, конвективная зона (расположение зон зависит от массы — см. 05).
3. Выключение тумблера возвращает внешний вид звезды.

### J5 — Rewind по HR-треку
1. Пользователь кликает по любой точке уже построенного эволюционного трека.
2. Симуляция ставится на паузу (если играла).
3. Состояние звезды восстанавливается к выбранному `HrTrackPoint` (age, params, stage, composition).
4. Маркер перемещается; «хвост» трека после точки обрезается или помечается как future (выбери **обрезать future** после rewind — проще и честнее).
5. Play продолжает эволюцию от этой точки вперёд.

### J6 — Финал: сверхновая / планетарная туманность / остаток
1. Для \(M \lesssim 8\,M_\odot\): после гиганта — планетарная туманность → белый карлик.
2. Для \(M \gtrsim 8\,M_\odot\): сверхновая → NS или BH по пределам (см. 04 / appendix A).
3. UI показывает финальный banner/статус остатка; clock останавливается на terminal stage (или медленно «тлеет» остаток — допустимо freeze на remnant).

### J7 — Пресеты масс
1. Кнопки пресетов: Красный карлик (0.2), Солнце (1), Массивная (8), Сверхмассивная (25) — точные значения в appendix A.
2. Пресет = set M (+ optionally Z) + Reset preview.

### J8 — Язык, тема, screenshot
1. Lang RU↔EN через `t(key)`.
2. Theme dark↔light меняет панели; canvas фон остаётся тёмным.
3. Screenshot сохраняет PNG текущего кадра **stellar canvas** (не обязательно весь UI).

## 1.5 Горячие клавиши

| Key | Действие |
|-----|----------|
| `Space` | Play / Pause |
| `R` | Reset |
| `C` | Toggle core cross-section |
| `1`–`4` | Пресеты масс (0.2 / 1 / 8 / 25) |
| `S` | Screenshot stellar canvas |
| `T` | Theme toggle |
| `G` | Language RU↔EN |
| `H` | Hotkeys help overlay |
| `Esc` | Закрыть overlay / снять rewind-hover hint |

Игнорировать hotkeys, если фокус в `<input>` / `<textarea>` / range во время drag (кроме Space — допустимо всегда, если не в text input).

## 1.6 Доступность (a11y)

1. Все кнопки и тумблеры — с `aria-label` (через i18n).
2. Play/Pause: `aria-pressed`.
3. Слайдеры: связанный `<label>`, `aria-valuemin/max/now`, видимое числовое значение.
4. HR: кликабельные точки трека доступны мышью; дополнительно кнопка «Шаг назад по треку» необязательна, но SVG обязан иметь `role="img"` и `<title>`/`aria-label` с кратким описанием.
5. Контраст текста панелей ≥ WCAG AA на обеих темах.
6. Фокус-кольцо видимо (`:focus-visible`).

## 1.7 Состояния приложения (продуктовые)

| State id | Описание |
|----------|----------|
| `idle` | Загружено, preview ZAMS, трек пуст, paused |
| `running` | Эволюция идёт |
| `paused` | Пауза; состояние сохранено |
| `rewound` | После клика по треку; future обрезан |
| `terminal` | Достигнут остаток; play no-op или disabled |

Переходы реализуй в stores / clock service явно.

## 1.8 Что запрещено в UX

- Карточки-«статистика» в hero/первом экране поверх звезды (badges, chips поверх corona).
- Purple cyberpunk glow как основной бренд.
- Подмена HR статическим PNG.
- Пропуск rewind «потому что сложно».
- Случайные «примерно» стадии без связи с массой.
